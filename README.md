# MVT AREA · דף המוצר

דף נחיתה של **MVT AREA**, תוסף Revit לחישוב שטחים ולהגשה לרובוט של רישוי זמין,
מוצר של **MAXIOM**.

כתובת: `mvt.maxiom.co.il`

## מבנה

```
index.html            הדף כולו: מבנה, עיצוב וקוד. קובץ אחד, בלי שלב בנייה.
assets/fonts.css      Heebo ו-Assistant מוטמעים כ-woff2 בתוך הקובץ.
assets/img/*.webp     צילומי מסך מהתוסף.
assets/teaser.mp4     סרטון ההדגמה שבראש הדף.
_headers              כותרות מטמון ואבטחה ל-Cloudflare Pages.
```

אין תלויות, אין `npm install`, אין תהליך בנייה. פתיחת `index.html` בדפדפן
מציגה את האתר כפי שהוא באוויר.

## פרסום

האתר מתפרסם ב-**Cloudflare Pages** ומחובר לריפו הזה. כל דחיפה ל-`main`
מפרסמת גרסה חדשה תוך פחות מדקה. אין הגדרות בנייה למלא, כי אין מה לבנות.

## הטופס

טופס "השארת פרטים" שולח `POST` ל-Web App של Google Apps Script, שכותב שורה
לגיליון הלידים ושולח מייל התראה. הכתובת מוגדרת ב-`index.html`, בקבוע
`LEADS_ENDPOINT`.

הבקשה נשלחת כ-`text/plain` ולא כ-`application/json`. זה מכוון: כך היא נחשבת
בקשה "פשוטה" ולא מפעילה preflight של CORS, ש-Apps Script אינו יודע לענות
עליו. התשובה חוזרת אטומה (`no-cors`), ולכן הדף מציג הצלחה מיד אחרי השליחה.

קוד ה-Apps Script אינו נמצא בריפו הזה מפני שהוא ציבורי, והקוד מכיל כתובות
מייל. הוא חי בעורך Apps Script המחובר לגיליון הלידים.

## הגופנים

Heebo ו-Assistant מופצים תחת רישיון SIL Open Font License 1.1 ומוטמעים כאן
כ-base64. ראו `assets/FONT-LICENSE.md`.

## החלפת חומרים

צילומי המסך והסרטון הם קבצים רגילים בתיקיית `assets`. להחלפה מספיק להעלות
קובץ בשם זהה, או לעדכן את הנתיב ב-`index.html`. אם יחס הגובה-רוחב של הסרטון
משתנה, יש לעדכן את `aspect-ratio` בכלל `.viewport video`.
